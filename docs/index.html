About me

Hi, I am Robert Rodriguez (also known as Skellent), a 17-year-old software developer based in Barquisimeto, Venezuela. I specialize in building dynamic web applications and architecting highly concurrent, automated systems.

My full-stack expertise focuses on Python, FastAPI, and vanilla JavaScript to create interactive platforms, including custom image-processing tools. I thrive on solving intricate backend challenges, leveraging asynchronous programming to optimize infrastructure for tasks like scalable, high-volume email dispatch.

Beyond web development, I am passionate about the intersection of software and physical engineering. This is best highlighted by my award-winning GreenHouse project, where I wrote embedded C++ logic for Arduino, designed and manufactured custom 3D-printed hardware, and built a seamless cross-platform companion app using Capacitor.js.
